# Fase 1 — Fundamentos de Programação

*Nível: Estagiário · [voltar para a trilha completa](../../AULAS.md)*

Do "Hello World" até ordenação e busca — os 10 tópicos que os 31 projetos de
`projects/estagiario/` praticam. Cada tópico é um documento separado: explicação,
exemplo genérico, um segundo exemplo num cenário parecido com o dos projetos da
DevTech, um exercício pra tentar sozinho, os erros mais comuns, e em quais projetos
aquele assunto aparece.

1. [Lógica de programação: algoritmos e pseudocódigo](01-logica-algoritmos-pseudocodigo.md)
2. [Variáveis, tipos de dados e operadores](02-variaveis-tipos-operadores.md)
3. [Estruturas condicionais (if, else, switch)](03-estruturas-condicionais.md)
4. [Estruturas de repetição (for, while, do-while)](04-estruturas-de-repeticao.md)
5. [Funções: parâmetros, retorno e escopo](05-funcoes-parametros-retorno-escopo.md)
6. [Arrays: criação, iteração e métodos essenciais](06-arrays.md)
7. [Objetos: propriedades, métodos e referências](07-objetos.md)
8. [Recursão e casos base](08-recursao.md)
9. [Algoritmos de ordenação (bubble sort, selection sort)](09-algoritmos-de-ordenacao.md)
10. [Algoritmos de busca (linear e binária)](10-algoritmos-de-busca.md)

Travou num projeto? Confira a linha **"Tópico da trilha"** no topo do README dele —
ela diz exatamente qual desses 10 arquivos ler antes de chamar o GitHub Copilot.
